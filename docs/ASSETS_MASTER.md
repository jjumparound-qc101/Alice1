# Master Asset List
Generated by `tools/assets_master.py` from the chapter lists. **Don't edit by hand**: change the chapter list in `docs/ART_PROMPTS.md` (and the reasons in `docs/CHAPTER_NN_ASSETS.md`), then run the script.

**Progress:** 75 of 353 images received. A box is ticked when a file with that name is in `source/ai/`.

## How to use this document
1. Use **one ChatGPT conversation** for everything, so the style and the characters stay the same.
2. Paste the **style block** below first, with the Tenniel references attached.
3. **Every Alice prompt:** attach the Alice model sheet (`source/ai/alice_turnaround.webp`) and add: "Match this model sheet exactly: same face, hair, collar, puffed sleeves, pinafore with pocket, sash bow, stockings and strap shoes, same proportions."
4. **Every White Rabbit prompt:** attach Tenniel plate 1.2 (https://victorianweb.org/art/illustration/tenniel/alice/1.2.html).
5. Attach the plate a prompt names (each chapter lists its reference links at the top).
6. Ask for the largest size; reject anything with grey wash, colour, a border or a signature. The game adds the colours the text names.
7. Upload with the **file name given**, as a normal message (not mid-task). Download originals; screenshots are lower quality.
8. Priority: each chapter ends with its "priority if time is short" order.
9. **Prompts that name a Tenniel plate:** generate them now, attaching the plate as the reference (owner, 2026-10-11). Cutting figures straight from high-resolution scans is an optional upgrade later.
10. **Card people:** numbered cards with a plain white face (the game prints the pips); court cards and the court's hearts with suit signs as solid black shapes (the game turns hearts and diamonds red). Details in the Chapter VIII section.

## Style block (paste first)
```
I'm making art for a game based on Alice's Adventures in Wonderland (1865). Everything must look like John Tenniel's original wood-engraved illustrations, shown in the attached references.

Style rules for every image in this conversation:
- Victorian wood-engraving style after John Tenniel: black ink on pure white paper.
- Shading ONLY with engraved lines: parallel hatching, cross-hatching, and short flicks. No gray tones, no wash, no gradients, no smudging.
- Confident, fine, slightly irregular line work, as if cut into a woodblock and printed.
- No color at all. No text, no signature, no frame or border.
- Pure white background unless I say otherwise.
- Match the proportions, costume and line quality of the attached Tenniel plates exactly.

Reply "ready" and wait for my first request.
```
